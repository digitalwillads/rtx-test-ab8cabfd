How we ran it

We rented the same two cards and ran the model exactly as its public recipe says.

The rented cards are the same chip as the card Will wants to buy. The model files and the server patches came from one public recipe, pinned to one version, so the test can be repeated on the real box.

Where each part ran

Will's Mac rents the box and drives it over a secure shell. On the box, Claude Code sends each step to the DeepSeek server and calls the fake Barbara's tools, and the server splits the model across the two cards and the computer's memory. The Mac runs Opus on the same tasks through the Claude API, so the two sides can be compared.

The parts

The box

Two RTX PRO 6000 Server Edition cards with 96 GB each, capped at 450 watts by the host. An AMD EPYC 9555P with 64 cores, 566 GiB of memory, and 500 GB of disk, rented on Vast.ai in France.

The model

DeepSeek V4.1 Flash, the October 17 release, which led the open-weight models on Artificial Analysis in November 2026. Its experts are compressed to 3 bits each so that it fits on two cards.

The recipe

A public recipe by diffbot holds the model files, the server patches, and the scripts to build and serve them. We pinned it to one version, so a rerun gets the same files and the same scripts.

No Docker on the box

A Vast box is itself a Docker container, so it cannot run Docker inside. A small stand-in runs the recipe's three Docker steps directly, unchanged, and passes 9 checks against the recipe's exact Docker calls.

Plain Claude Code

Both models ran Claude Code with empty settings and no personal instructions, each run in a fresh folder outside the home folder. DeepSeek's Claude Code ran on the box, so no file from Will's Mac reached the rented machine.

Test data only

The box belongs to a stranger, so every task used made-up data, including the three clients in the fake Barbara. No client data and no secrets went to the box.

What it cost

For Jacob: run it again

The kit lives in ~/Desktop/projects/gpu-box-test (local git; see its README). On the Mac, with the Vast key in KeyMaster as VAST_API_KEY (tag gpu-test):

./local.sh login email          # Vast's two-factor login; then ./local.sh login email <code>
./local.sh rent                 # cheapest box that fits; 6-hour destroy timer
./local.sh push
./local.sh ssh 'bash /workspace/kit/box.sh setup'   # 332 GB download + native build, ~6 min
./local.sh ssh 'bash /workspace/kit/box.sh serve'   # ~5 min to warm
./local.sh ssh 'QUICK=1 bash /workspace/kit/box.sh bench'
./local.sh ssh 'REPS=3 bash /workspace/kit/box.sh tasks'
./local.sh opus                 # the Opus side, on the Mac
./local.sh destroy              # copies results, destroys, confirms it is gone

The recipe is Hugging Face diffbot/DeepSeek-V4.1-Flash-EXL3-3bpw-2x-RTX-PRO-6000 at revision 451f7dcb8ecb0502a963f3314e16b34c5a8ce5ae, on the base image vllm/vllm-openai@sha256:8896fd7b…e6e339a (the nightly tag is gone). The server serves an Anthropic-style /v1/messages endpoint, so Claude Code points at it with ANTHROPIC_BASE_URL and ANTHROPIC_AUTH_TOKEN.

On the real box, use the recipe's own Docker steps instead of box.sh setup. Then box.sh bench and box.sh tasks work as they are, because they only need the server on port 8000, and the numbers can be compared with these.
