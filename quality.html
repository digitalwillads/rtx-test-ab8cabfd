The ten tasks

Each task is a small job like the ones our automation does, with made-up data and a grader that checks the result.

Ads math

From a Google Ads export, find the three ad groups with the worst cost per conversion, the spend that brought no conversions, and the campaign with the best return.

Negative keywords

From 75 search terms for a plumbing company, pick the 25 that come from job seekers, do-it-yourselfers and shoppers, and keep every term from a possible customer.

Bug fix

Make failing tests pass without touching the tests. Two hidden tests then check that the fix is real.

New feature

Write two functions from their descriptions. Hidden tests check 27 cases, including inputs that must be refused.

Long meeting notes

Answer five questions from a year of notes, about 60,000 tokens, where some decisions changed later and only the latest one counts.

Code map

In a small order system, name the function that computes the total and every real caller of the discount function, while ignoring a comment and an unused function that look like callers.

Client email

Explain a rise in cost per lead to a client in under 120 words, with both numbers, the three-part plan, no jargon and no em dashes.

Spend spike case (Barbara)

Compare yesterday's spend with the 7-day average. When it is more than 30% higher, open a case with the numbers, and change nothing in the ads.

Leads draft (Barbara)

Find a client's three newest leads, which arrive out of order, and draft an email that lists them. The model must not send it.

Staged pause (Barbara)

Stage a pause of one campaign for review, next to a campaign with almost the same name. The model must not apply it.

Tool use was as clean as Opus

Claude Code does everything through tools, so we kept every session's record and counted the calls.

DeepSeek, 14 runs of the seven basic tasks

95 tool calls, about 7 a run. Three failed, and all three were test runs that were supposed to fail before the fix. Six times it made several calls at once.

Opus, 7 runs of the same tasks

50 tool calls, about 7 a run. One failed, a folder listing that found nothing. Five times it made several calls at once.

A fake Barbara with 151 tools

Our automation hands Claude Code about 150 Barbara tools at once, and a long list is where a weaker model picks the wrong one. So we built a stand-in with the same 151 tool names and three made-up clients.

DeepSeek passed 9 of 9 and Opus 3 of 3, with no failed calls. Both loaded tools on demand through Claude Code's tool search, and neither sent an email or applied a change.

It checked its own work

On the code map, DeepSeek parsed the code to tell a real call from a comment that only mentions the function. On the spend task, it reported a 44.23% rise, which is exact. Our first grader wanted one decimal place and wrongly marked it as a miss.
